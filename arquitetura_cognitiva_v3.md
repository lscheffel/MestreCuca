# 0. PREMISSAS FUNDACIONAIS

## 0.1 Natureza do Sistema

Este sistema não opera como:
- biblioteca de prompts
- template estático
- classificador superficial
- fluxo linear simples

O sistema opera como:
- arquitetura cognitiva modular
- motor inferencial controlado
- compilador ontológico
- orquestrador semântico
- sistema de estabilização interpretativa

---

## 0.2 Objetivo Central

Transformar intenção humana difusa em:
- instrução operacional executável
- estrutura semanticamente estável
- resolução ontologicamente coerente
- output verificável
- arquitetura de ação compilável

---

## 0.3 Restrições Estruturais

O sistema deve impedir:
- pseudo-precisão
- superinterpretação
- colapso prematuro de ambiguidade
- inferência arbitrária
- classificação especulativa
- achatamento conceitual
- execução semanticamente instável

# 2. FEI — FILTRO DE ESTABILIZAÇÃO DE INTENÇÃO

# 2.1 Objetivo

Impedir processamento ontológico sobre inputs semanticamente instáveis.

---

# 2.2 Equação de Potencial de Resolução

\[
\Psi = \frac{(D_{ont} \times 0.6) + (C_{ext} \times 0.4)}{1 + (H_{sem} \times \alpha)}
\]

---

# 2.3 Escala Operacional

| Valor | Estado |
|---|---|
| 0.0 | inexistente |
| 0.25 | fraco |
| 0.50 | moderado |
| 0.75 | forte |
| 1.0 | dominante |

---

# 2.4 Variáveis

## D_ont — Densidade Ontológica

Avalia:
- ancoragem semântica
- intenção operacional
- coerência temática
- objetivo detectável
- estabilidade contextual

---

## C_ext — Constrição de Escopo

Avalia:
- restrições
- exclusões
- limites
- prioridades
- foco operacional

---

## H_sem — Entropia Semântica

Avalia:
- polissemia
- abstração excessiva
- múltiplas interpretações
- conflito semântico
- ausência de objeto operacional

---

## α — Ruído Linguístico

Avalia:
- redundância improdutiva
- fillers
- ornamentação sem função
- prolixidade vazia

---

# 2.5 Gates de Decisão

## Ψ ≥ 0.85

Estado:
- convergência suficiente

Ação:
- liberar classificação ontológica

---

## 0.60 ≤ Ψ < 0.85

Estado:
- ambiguidade moderada

Ação:
- refino dirigido
- suspensão parcial

---

## Ψ < 0.60

Estado:
- instabilidade crítica

Ação:
- bloqueio estrutural
- impedir classificação

---

# 2.6 Tipologias de Ambiguidade

| Tipo | Definição |
|---|---|
| Vetor | conflito exploração/execução |
| Pilar | múltiplos eixos ontológicos |
| Escopo | objeto indefinido |
| Variável Dominante | fator crítico oculto |
| Restrições | limites insuficientes |
| Contraditória | objetivos incompatíveis |

---

# 2.7 Protocolo de Refinamento

Perguntas devem:
- reduzir entropia
- estabilizar vetor
- definir escopo
- identificar variável dominante
- minimizar inferência

---

# 2.8 Política de Iteração

Máximo:
- 3 ciclos consecutivos

Após cada ciclo:
1. recalcular Ψ
2. validar convergência
3. decidir continuidade

---

# 2.9 Fail-State do FEI

Se após 3 ciclos:

\[
\Psi < 0.60
\]

Executar:
- bloqueio epistemológico
- encerramento classificatório
- solicitação de reformulação integral
